# AAU public university website

Static public website served by the existing American Allied University Vercel project. Set the Vercel Root Directory to `website`; Framework Preset: Other; no build/install command or output directory override.

Programs, admissions, tuition, mission, and contact pages are public. Student Login links to the existing learning platform. Request Information opens the existing inquiry service, preserving its saved records and form processing. No student data, backend credentials, or database copies are included here.

Previous uploaded versions remain in the repository folders for reference.
